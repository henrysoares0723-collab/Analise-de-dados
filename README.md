# 📊 Análise de Dados de Clientes

Este projeto foi desenvolvido como parte do meu processo de aprendizado no curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

A proposta foi utilizar Python para realizar uma análise exploratória de uma base de dados de clientes de um banco, praticando conceitos de **tratamento de dados, análise estatística e visualização de informações**.
---

## 🎯 Objetivo do projeto

O principal objetivo foi aprender, na prática, como trabalhar com uma base de dados utilizando Python.

Durante o desenvolvimento, foram aplicadas técnicas para:

- Importar uma base de dados em formato CSV;
- Limpar e organizar os dados;
- Remover informações que não seriam utilizadas na análise;
- Identificar informações estatísticas da base;
- Calcular a distribuição percentual de categorias;
- Criar gráficos para facilitar a interpretação dos dados;
- Observar possíveis padrões e relações presentes nos dados.

A ideia não foi desenvolver um sistema completo de análise de dados, mas sim utilizar o projeto como uma **etapa prática de aprendizado**.
